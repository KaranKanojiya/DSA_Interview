Stack + Min-Stack — Implement from Scratch

LIFO with push/pop/peek all O(1). Min-Stack tracks the minimum at each level using a parallel stack — getMin() in O(1). The trick: when you push, also push the current minimum onto a second stack. When you pop, pop from both. LeetCode #155.

Core Idea

LIFO — Last In, First Out

A stack is like a stack of plates: you can only add to the top (push) and remove from the top (pop). The last element pushed is the first one popped.

Used in: function call stack, expression evaluation, undo/redo, DFS, balanced parentheses checking.

The Min-Stack Trick

Maintain a parallel array (minData[]) where each position stores the minimum value of all elements from the bottom of the stack up to that position.

  • push(val): minData[top] = min(val, minData[top-1])
  • pop(): just decrement top — min pops automatically
  • getMin(): return minData[top] — O(1)
2

Min-Stack — Parallel Tracking

Key insight: Each level of minData[] records the minimum of everything below it (inclusive). When you pop, the previous minimum is automatically revealed at minData[top-1]. No re-scanning needed.
3

Operations — Step by Step

push(value)

  1. Check overflow: top == capacity-1
  2. Increment top
  3. data[top] = value
  4. minData[top] = min(value, minData[top-1])

pop()

  1. Check underflow: top == -1
  2. Save data[top]
  3. Null out both data[top] and minData[top]
  4. Decrement top, return saved value

push(value) — O(1)

with min tracking
public void push(E value) {
    if (top == data.length - 1)
        throw new IllegalStateException("Stack overflow");
    top++;
    data[top] = value;

    // Track current minimum at this level
    if (top == 0) {
        minData[top] = value;
    } else {
        @SuppressWarnings("unchecked")
        E currentMin = (E) minData[top - 1];
        minData[top] = value.compareTo(currentMin) < 0
            ? value : currentMin;
    }
}
3

pop() — O(1)

remove top
@SuppressWarnings("unchecked")
public E pop() {
    if (isEmpty())
        throw new IllegalStateException("Stack underflow");
    E value = (E) data[top];
    data[top] = null;
    minData[top] = null;
    top--;
    return value;
}
4

peek() & getMin() — O(1)

read top
@SuppressWarnings("unchecked")
public E peek() {
    if (isEmpty())
        throw new IllegalStateException(
            "Stack is empty");
    return (E) data[top];
}
@SuppressWarnings("unchecked")
public E getMin() {
    if (isEmpty())
        throw new IllegalStateException(
            "Stack is empty");
    return (E) minData[top];
}

Common Follow-ups

Implement Queue using Stacks

Two stacks: pushStack for enqueue, popStack for dequeue. Transfer all from pushStack → popStack when popStack is empty — reverses order for FIFO. Amortized O(1). LeetCode #232. See the Queue Using Stacks canvas.

Browser back/forward

Two stacks: backStack and forwardStack. Navigate to URL → push current onto backStack. Back → pop from backStack, push onto forwardStack. Forward → pop from forwardStack, push onto backStack. Navigate to new URL → clear forwardStack.

Undo/Redo system

Same two-stack pattern as browser history. undoStack stores actions, redoStack stores undone actions. New action → clear redoStack. This is the Command pattern in OOP — each action is an object with execute() and undo() methods.

Balanced parentheses

Push opening brackets, pop on closing brackets. If pop result doesn't match → unbalanced. If stack not empty at end → unbalanced. Extend to {}, [], (). O(n) time, O(n) space. LeetCode #20.

Edge Cases & Gotchas

Stack overflow — Fixed-size array means push() can overflow. Either throw an exception (our approach) or auto-resize like ArrayList. Java's ArrayDeque-based stack auto-resizes.
Stack underflow — pop() or peek() on an empty stack. Always check isEmpty() first or throw. The top == -1 convention makes this check clean.
getMin on empty stack — Must throw or return a sentinel. Don't access minData[-1]. This edge case is commonly tested in interviews.
Space optimization: Instead of storing min at every level, only push to minStack when the new value is ≤ current min. Pop from minStack only when the popped value equals the current min. Saves space when elements are mostly ascending.
