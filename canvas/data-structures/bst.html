Binary Search Tree — Implement from Scratch

left < node < right. Insert, search, and delete all run in O(log n) average. Delete has 3 cases: leaf node, one child, and two children (replace with in-order successor). The fundamental ordered data structure — basis for AVL trees, Red-Black trees, and TreeMap.

Core Idea

BST Property

For every node:
All left descendants < node < all right descendants

This invariant enables binary search: at each node, you eliminate half the remaining candidates. Average case gives O(log n) for insert, search, and delete.

In-order traversal (left → node → right) yields elements in sorted order.

Why BST?

  • Sorted order — in-order traversal gives sorted output
  • Dynamic — unlike sorted array, insert/delete are efficient
  • Range queries — find all elements in [lo, hi] efficiently
  • Predecessor / successor — O(log n) finding next/prev element

Caveat: without balancing, worst case is O(n) (degenerate tree = linked list)

Delete — 3 Cases

Case 1: Leaf

Node has no children. Simply remove it — set parent's pointer to null.

Example: delete 4 → just remove it from 6's left

Case 2: One Child

Node has one child. Replace the node with its child — the child takes the node's spot.

Example: delete 10 → replace with 14 (its only child subtree)

Case 3: Two Children

Find the in-order successor (smallest node in right subtree). Copy its value to the target node, then delete the successor (which has at most one child).

Example: delete 3 → successor is 4, copy 4 into 3's spot, delete old 4 (leaf)

Why in-order successor? It's the smallest value greater than the deleted node — swapping it in preserves the BST property. You could also use the in-order predecessor (largest in left subtree).

insert — Recursive

O(log n) avg
public void insert(int val) {
    root = insertRec(root, val);
}

private TreeNode insertRec(TreeNode node, int val) {
    if (node == null) return new TreeNode(val);

    if (val < node.val) {
        node.left = insertRec(node.left, val);    // go left
    } else if (val > node.val) {
        node.right = insertRec(node.right, val);   // go right
    }
    // val == node.val → duplicate, skip (or handle as desired)
    return node;
}

search — Recursive

O(log n) avg
public boolean search(int val) {
    return searchRec(root, val);
}

private boolean searchRec(TreeNode node, int val) {
    if (node == null) return false;
    if (val == node.val) return true;
    return val < node.val
        ? searchRec(node.left, val)
        : searchRec(node.right, val);
}

delete — 3 Cases with In-order Successor

O(log n) avg
public void delete(int val) {
    root = deleteRec(root, val);
}

private TreeNode deleteRec(TreeNode node, int val) {
    if (node == null) return null;

    if (val < node.val) {
        node.left = deleteRec(node.left, val);
    } else if (val > node.val) {
        node.right = deleteRec(node.right, val);
    } else {
        // FOUND the node to delete

        // Case 1 & 2: leaf or one child
        if (node.left == null) return node.right;
        if (node.right == null) return node.left;

        // Case 3: two children → in-order successor
        TreeNode successor = findMin(node.right);
        node.val = successor.val;  // copy successor's value
        node.right = deleteRec(node.right, successor.val);  // delete successor
    }
    return node;
}

// Smallest node in a subtree = leftmost
private TreeNode findMin(TreeNode node) {
    while (node.left != null) {
        node = node.left;
    }
    return node;
}
// In-order: left → root → right = sorted
public void inorder() {

private void inorderRec(TreeNode node) {
    if (node == null) return;

isValidBST

verification
public boolean isValidBST() {
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

private boolean validate(TreeNode node, long min, long max) {
    if (node == null) return true;
    if (node.val <= min || node.val >= max) return false;
    return validate(node.left, min, node.val)
        && validate(node.right, node.val, max);
}
Use long for bounds — Using Integer.MIN_VALUE / MAX_VALUE fails when the tree contains those values. Use Long.MIN_VALUE / Long.MAX_VALUE or null with null checks.

Common Follow-ups

AVL / Red-Black Trees for balance?

AVL: height difference between left and right subtrees ≤ 1. Rotations (left, right, left-right, right-left) after insert/delete to rebalance. Guarantees O(log n) height. Better for read-heavy workloads (stricter balance).

Red-Black: nodes are red or black with 5 properties ensuring no path is more than 2× longer than any other. Less strict than AVL → fewer rotations on insert/delete. Used by Java's TreeMap and TreeSet.

Kth Smallest Element (LC #230)?

In-order traversal stops at the Kth element. Use a counter that decrements at each visit. When counter hits 0, you've found the Kth smallest. O(H + K) time. For repeated queries, augment each node with a leftCount field for O(log n) lookups.

Lowest Common Ancestor (LC #235)?

In a BST: if both values are less than the current node → go left. If both are greater → go right. Otherwise, the current node is the LCA (the split point). O(log n) for balanced BST. Much simpler than the general binary tree LCA which needs parent pointers or recursion.

Serialize / Deserialize BST (LC #449)?

Serialize: preorder traversal → comma-separated string. Deserialize: use the BST property with upper/lower bounds. For each value, if it fits within [min, max], create a node and recursively build left (max = val) and right (min = val). O(n) time, no null markers needed (unlike general binary tree).

Edge Cases & Gotchas

Degenerate tree → O(n) — Inserting sorted data (1, 2, 3, 4, 5) creates a linked list. All operations become O(n). This is why self-balancing trees (AVL, Red-Black) exist. Always mention this trade-off in interviews.
Duplicate handling — Pure BST has no duplicates (left < node < right). If you need duplicates: store a count per node, allow left ≤ node < right, or use a separate data structure. Clarify with the interviewer.
Deleting the root — Works the same as any node deletion. The trick is returning the new root from the recursive call. The caller pattern root = deleteRec(root, val) handles root changes automatically.
isValidBST common mistake — Checking only left.val < node.val < right.val is wrong. You must check that ALL left descendants are less, not just the immediate child. Pass min/max bounds down the recursion.
