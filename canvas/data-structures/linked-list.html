Core Idea

What is a Doubly Linked List?

A linear collection where each node stores a value and two pointers: prev (previous node) and next (next node). The list maintains head and tail references for O(1) access to both ends.

Unlike arrays, there's no random access — you must traverse from head or tail to reach a specific index.

Node Structure — Doubly Linked

Two pointers per node: prev allows O(1) removal of any node (given a reference) and O(1) removeLast() via the tail pointer — impossible with singly linked lists without traversal.

Operations — Step by Step

addFirst(value)

  1. Create new Node
  2. If list is empty → head = tail = node
  3. Else → node.next = head, head.prev = node, head = node
  4. size++

addLast(value)

  1. Create new Node
  2. If list is empty → head = tail = node
  3. Else → tail.next = node, node.prev = tail, tail = node
  4. size++

removeFirst()

  1. Save head.value
  2. head = head.next
  3. If new head != null → head.prev = null
  4. Else → tail = null (list is now empty)
  5. size-- and return value

reverse()

  1. Walk every node: swap prev ↔ next
  2. After loop: swap head ↔ tail
  3. That's it — all links reversed in O(n)

addFirst & addLast — O(1)

insertion
public void addFirst(E value) {
    Node<E> node = new Node<>(value);
    if (head == null) {
        head = tail = node;
    } else {
        node.next = head;
        head.prev = node;
        head = node;
    }
    size++;
}
public void addLast(E value) {
    Node<E> node = new Node<>(value);
    if (tail == null) {
        head = tail = node;
    } else {
        tail.next = node;
        node.prev = tail;
        tail = node;
    }
    size++;
}
4

removeFirst & removeLast — O(1)

deletion
public E removeFirst() {
    if (head == null)
        throw new IllegalStateException("Empty");
    E value = head.value;
    head = head.next;
    if (head != null) head.prev = null;
    else tail = null;
    size--;
    return value;
}
public E removeLast() {
    if (tail == null)
        throw new IllegalStateException("Empty");
    E value = tail.value;
    tail = tail.prev;
    if (tail != null) tail.next = null;
    else head = null;
    size--;
    return value;
}
5

removeAt(index) — O(n)

arbitrary removal
public E removeAt(int index) {
    Node<E> node = getNode(index);
    if (node.prev != null) node.prev.next = node.next;
    else head = node.next;
    if (node.next != null) node.next.prev = node.prev;
    else tail = node.prev;
    size--;
    return node.value;
}
6

reverse() — O(n)

swap all pointers
public void reverse() {
    Node<E> current = head;
    while (current != null) {
        Node<E> temp = current.next;
        current.next = current.prev;   // swap next ↔ prev
        current.prev = temp;
        current = temp;                // advance (using old next)
    }
    Node<E> temp = head;
    head = tail;
    tail = temp;                       // swap head ↔ tail
}

getNode(index) — O(n) helper

traversal
private Node<E> getNode(int index) {
    if (index < 0 || index >= size)
        throw new IndexOutOfBoundsException("Index: " + index);
    Node<E> current = head;
    for (int i = 0; i < index; i++)
        current = current.next;
    return current;
}
Optimization: If index > size/2, start from tail and walk backward — cuts traversal time in half on average. Java's LinkedList does this.

Common Follow-ups

Detect cycle — Floyd's Tortoise & Hare

Two pointers: slow moves 1 step, fast moves 2 steps. If they meet → cycle exists. To find the cycle start: reset slow to head, advance both 1 step at a time — they meet at the cycle entry. O(n) time, O(1) space. LeetCode #141/#142.

Find middle node

Slow/fast pointer: when fast reaches the end, slow is at the middle. One pass, O(n) time, O(1) space. Used as a building block for merge sort on linked lists. LeetCode #876.

Merge two sorted linked lists

Use a dummy head, compare nodes from both lists, attach smaller one. O(n+m) time. The recursive version is elegant but uses O(n+m) stack space. LeetCode #21.

Reverse in groups of k

Reverse every k nodes in place. Track group boundaries, reverse the sub-list, reconnect. O(n) time, O(1) space. LeetCode #25 (Hard). Common follow-up to basic reverse.

Edge Cases & Gotchas

Empty list operations — removeFirst/removeLast on empty list must throw. Always check head == null or tail == null before accessing.
Single node — After removing the only node, both head AND tail must be set to null. Forgetting to null the tail leaves a dangling pointer.
Reverse: advance before overwriting — In reverse(), save current.next in a temp variable BEFORE swapping pointers. Otherwise you lose the reference to the next node and the loop breaks.
prev pointer maintenance — Every insertion and removal must update BOTH next and prev pointers. Missing one direction is the #1 bug in doubly linked list implementations.
