Core Idea

What is a Trie?

A tree where each edge represents a character and each path from root to a node spells a prefix. Nodes marked as isEndOfWord indicate complete words. Shared prefixes share the same path — massive space saving for dictionaries.

Named after retrieval — pronounced "try" to distinguish from "tree".

Why Trie over HashSet?

  • Prefix search — HashSet can't do "find all words starting with 'app'" efficiently
  • Autocomplete — traverse to prefix node, then DFS to collect all completions
  • Sorted iteration — DFS on a trie yields words in lexicographic order
  • Pattern matching — wild cards, word search boards

HashSet wins on simple contains() — O(1) avg vs O(m) for trie. Use trie when you need prefix operations.

2

Trie Structure — "cat", "car", "card"

Shared prefix "ca" — "cat", "car", "card" all share the path root→c→a. Only the branch point differs. This is why tries are space-efficient for words with common prefixes.
3

Array vs HashMap Children

Array: children[26]

  • O(1) child lookup: children[ch - 'a']
  • Fixed 26 slots per node (a-z only)
  • Wastes space if most slots are null
  • Best for interview: simple, fast, predictable

HashMap: Map<Character, Node>

  • O(1) amortized child lookup
  • Only allocates for existing children
  • Supports any character set (Unicode, etc.)
  • More overhead per entry (HashMap node objects)

Operations — Step by Step

insert(word)

  1. Start at root
  2. For each char: compute index = ch - 'a'
  3. If children[index] is null → create new node
  4. Move to children[index]
  5. After last char: mark isEndOfWord = true

search(word) / startsWith(prefix)

  1. Start at root
  2. For each char: compute index = ch - 'a'
  3. If children[index] is null → return false
  4. Move to children[index]
  5. search: return node.isEndOfWord
  6. startsWith: return true (node exists = prefix exists)

TrieNode — Inner Class

node structure
private static class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a-z
    boolean isEndOfWord = false;
}

private final TrieNode root = new TrieNode();
2

insert(word)

O(m)
public void insert(String word) {
    TrieNode curr = root;
    for (char ch : word.toCharArray()) {
        int idx = ch - 'a';
        if (curr.children[idx] == null) {
            curr.children[idx] = new TrieNode();  // create path
        }
        curr = curr.children[idx];  // traverse down
    }
    curr.isEndOfWord = true;  // mark as complete word
}
3

search(word) & startsWith(prefix)

O(m)
public boolean search(String word) {
    TrieNode node = findNode(word);
    return node != null && node.isEndOfWord;
}

public boolean startsWith(String prefix) {
    return findNode(prefix) != null;
}

// Shared helper — traverses the trie following each character
private TrieNode findNode(String s) {
    TrieNode curr = root;
    for (char ch : s.toCharArray()) {
        int idx = ch - 'a';
        if (curr.children[idx] == null) return null;
        curr = curr.children[idx];
    }
    return curr;
}
findNode is the shared traversal logic. search checks isEndOfWord on the result; startsWith just checks that the node exists.
4

delete(word) — Recursive

O(m)
public boolean delete(String word) {
    return deleteHelper(root, word, 0);
}

private boolean deleteHelper(TrieNode node, String word, int depth) {
    if (node == null) return false;

    if (depth == word.length()) {
        if (!node.isEndOfWord) return false;  // word doesn't exist
        node.isEndOfWord = false;
        return isEmpty(node);  // can delete node if no children
    }

    int idx = word.charAt(depth) - 'a';
    boolean shouldDelete = deleteHelper(node.children[idx], word, depth + 1);

    if (shouldDelete) {
        node.children[idx] = null;  // remove the child link
        return !node.isEndOfWord && isEmpty(node);
    }
    return false;
}

private boolean isEmpty(TrieNode node) {
    for (TrieNode child : node.children) {
        if (child != null) return false;
    }
    return true;
}

Common Follow-ups

Autocomplete / Top-K prefix (LC #642)?

Navigate to the prefix node, then DFS to collect all words below it. For top-K: store a frequency count in each end-of-word node. Use a min-heap of size K during DFS to track the top-K results. Alternatively, pre-compute top-K at each node for O(m) query time (space trade-off).

Word Search II (LC #212)?

Build a trie from the word list. Run DFS from each cell on the board, following trie edges. If you reach an isEndOfWord node, you found a word. Prune branches with no matching trie path. Much faster than searching each word individually. O(M × N × 4^L) worst case but trie pruning makes it practical.

Replace Words (LC #648)?

Insert all root words into a trie. For each word in the sentence, traverse the trie character by character. If you hit an isEndOfWord node, replace the word with the root (shortest prefix match). If you exhaust the trie path, keep the original word. O(n × m) where n = words, m = avg word length.

Map Sum Pairs (LC #677)?

Each trie node stores a sum value. On insert, update the sum at every node along the path. For sum(prefix), navigate to the prefix node and return its sum. Handle updates by storing old values and adjusting the delta. O(m) for both operations.

Edge Cases & Gotchas

Empty string — Inserting "" marks the root's isEndOfWord = true. search("") should return true, startsWith("") is trivially true. Make sure your loop handles zero iterations correctly.
Prefix exists but isn't a word — "car" is in the trie but "ca" is not a word. search("ca") must return false (isEndOfWord is false), while startsWith("ca") returns true. This distinction is the #1 trie interview trap.
Delete non-existent word — Deleting a word that doesn't exist must not corrupt other words. Check isEndOfWord at the target depth before removing any nodes. Only prune nodes that have no other children and aren't end-of-word for other paths.
Case sensitivity — If the input may include uppercase letters, normalize to lowercase first or use children[52] (a-z + A-Z). Interview tip: always clarify the character set with the interviewer.
